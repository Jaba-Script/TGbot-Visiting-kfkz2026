# 📊 Бот відвідуваності

Telegram-бот для відмічання відсутніх студентів на парах з автоматичним записом у Google Таблиці.

---

## 🗂 Структура проєкту

```
attendance_bot/
├── credentials.json   # ключ сервісного акаунту Google (не публікувати!)
├── .env               # токен бота і налаштування
├── requirements.txt   # залежності Python
├── config.py          # завантаження змінних середовища
├── sheets.py          # робота з Google Таблицями
├── keyboards.py       # інлайн-клавіатури
├── states.py          # FSM-стани діалогу
├── handlers.py        # логіка бота
└── main.py            # точка входу
```

---

## ⚙️ Налаштування

### 1. Клонуй або скачай проєкт

### 2. Встанови залежності
```bash
pip install -r requirements.txt
```

### 3. Створи файл `.env`
Скопіюй `.env.example` → `.env` і заповни:
```
BOT_TOKEN=токен_від_BotFather
SPREADSHEET_ID=id_таблиці_з_посилання
ALLOWED_USERS=123456789
CREDENTIALS_FILE=credentials.json
```

> **SPREADSHEET_ID** — тільки ID з посилання, без `/edit?...`  
> Приклад: `docs.google.com/spreadsheets/d/`**ЦЕЙ_РЯДОК**/edit  
> **ALLOWED_USERS** — Telegram ID відповідальної особи (дізнатись через @userinfobot)

### 4. Налаштуй Google Таблицю

Таблиця повинна мати такі листи (назви точно як тут):

#### `Schedule` — розклад
| Пара | Пн | Вт | Ср | Чт | Пт |
|------|----|----|----|----|-----|
| 1    | Математика | — | Фізика | Математика | Історія |
| 2    | Фізика | Англійська | — | Англійська | Математика |

Порожня клітинка або `—` означає що пари немає.  
Використовуй **перевірку даних** (Data validation → Dropdown) для назв предметів, щоб уникнути опечаток.

#### `Студенти` — список групи
| Студент |
|---------|
| Іваненко Олексій |
| Петренко Марія |
| ... |

#### `Log` — журнал (бот пише сюди)
| Дата | День | Пара | Предмет | Студент | Статус | Відмітив | Час |
|------|------|------|---------|---------|--------|----------|-----|

Перший рядок — заголовки, решта заповнює бот автоматично.

#### Листи по предметах + загальний
Формули для цих листів додаються окремо після запуску бота.

### 5. Дай доступ сервісному акаунту
Відкрий `credentials.json` → знайди `client_email` → розшар таблицю на цей email як **Редактор**.

---

## 🚀 Запуск

```bash
python main.py
```

Напиши боту `/start` — якщо відповів, все налаштовано правильно.

---

## 💬 Команди бота

| Команда | Дія |
|---------|-----|
| `/start` | Головне меню |
| `/mark` | Розпочати відмічання пари |
| `/cancel` | Скасувати поточну дію |

---

## 🔄 Сценарій відмічання

1. Відправ `/mark`
2. Бот покаже пари на сьогодні з розкладу
3. Обери потрібну пару
4. Натискай на імена відсутніх студентів (✅ → ❌)
5. Натисни **Підтвердити** — дані запишуться в `Log`

## 📊 Зведена таблиця відвідуваності

Лист **«Зведена»** — рядки: студенти, стовпці: робочі дні навчального року.  
Значення в кожній клітинці — кількість пропущених годин за цей день (1 пара = 2 год).  
Крайній правий стовпець **«Разом»** — сума за весь рік.

Створюється один раз скриптом (бот туди нічого не пише, все рахується формулами з Log):

```bash
python setup_summary.py
```

Перед запуском перевір дати навчального року у верхній частині файлу `setup_summary.py`:
```python
YEAR_START = date(2026, 9, 1)   # початок навчального року
YEAR_END   = date(2027, 6, 30)  # кінець навчального року
```
